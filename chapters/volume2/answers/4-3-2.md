**3.** [题目](../sec-4-3-2.md#ex-4-3-2-3) 由 $u\equiv u_i\quad(\text{modulo }m_i)$ 可推导出 $u\equiv u_i\quad(\text{modulo }\gcd(m_i,m_j))$, 所以有解时同余式 $u_i\equiv u_j\quad(\text{modulo }\gcd(m_i,m_j))$ 必然成立. 此外, 如果对所有 $j$ 都有 $u\equiv v\quad(\text{modulo }m_j)$, 则 $u-v$ 是 $\operatorname{lcm}(m_1,\ldots,m_r)=m$ 的倍数. 因此最多有一个解.

我们可用一种非构造性的方式完成证明. 我们将统计满足条件 $0\le u_j<m_j$ 和 $u_i\equiv u_j\quad(\text{modulo }\gcd(m_i,m_j))$ 的 $r$ 元组 $(u_1,\ldots,u_r)$ 的数目. 如果数目为 $m$ 就必定有解, 因为当 $u$ 从 $a$ 变动到 $a+m-1$ 时, $(u\bmod m_1,\ldots,u\bmod m_r)$ 会取 $m$ 个不同的值. 假设我们已经选取了满足给定条件的 $u_1,\ldots,u_{r-1}$, 则应取 $u_r$ 满足 $u_r\equiv u_j\quad(\text{modulo }\gcd(m_j,m_r))$, $1\le j<r$. 根据关于 $r-1$ 个数的广义中国剩余定理, 共有

$$
\begin{aligned}
m_r/\operatorname{lcm}(\gcd(m_1,m_r),\ldots,\gcd(m_{r-1},m_r))&=m_r/\gcd(\operatorname{lcm}(m_1,\ldots,m_{r-1}),m_r)\\
&=\operatorname{lcm}(m_1,\ldots,m_r)/\operatorname{lcm}(m_1,\ldots,m_{r-1})
\end{aligned}
$$

种选取方法. [此证明利用了 4.5.2 节的恒等式 (10) (11) (12) (14).]

一种推广了 $(25)$ 的构造性证明 [弗伦克尔, Proc.Amer.Math.Soc.14(1963), 790-791] 如下. 令 $M _ { j } = \operatorname { l c m } ( m _ { 1 } , \ldots , m _ { j } )$. 我们要求 $u = v_{r}M_{r - 1} + \cdots + v_{2}M_{1} + v_{1}$, 其中 $0 \leq v _ { j } < M _ { j } / M _ { j - 1 }$. 假设 $v _ { 1 } ,$ $\cdots , v _ { j - 1 }$ 已经求出, 则接下来要求解同余式

$$
v _ { j } M _ { j - 1 } + v _ { j - 1 } M _ { j - 2 } + \cdots + v _ { 1 } \equiv u _ { j } \quad ( \operatorname { m o d u l o } \quad m _ { j } ) .
$$

由假设条件可知, 对于 $i < j$, 我们有 $v _ { j - 1 } M _ { j - 2 } + \cdots + v _ { 1 } \equiv u _ { i } \equiv u _ { j }$ $(\text{modulo }\gcd(m_i,m_j))$. 从而 $c = u _ { j } - ( v _ { j - 1 } M _ { j - 2 } + \cdots + v _ { 1 } )$ 是

$$
\operatorname { l c m } ( \operatorname* { g c d } ( m _ { 1 } , m _ { j } ) , \ldots , \operatorname* { g c d } ( m _ { j - 1 } , m _ { j } ) ) = \operatorname* { g c d } ( M _ { j - 1 } , m _ { j } ) = d _ { j }
$$

的倍数. 所以, 我们必须求解 $v _ { j } M _ { j - 1 } \equiv c ( \bmod { m _ { j } } )$. 根据欧几里得算法, 存在 $c _ { j }$ 使得 $c _ { j } M _ { j - 1 } \equiv d _ { j }\ (\text{modulo }m_{j})$, 因此可取

$$
v _ { j } = ( c _ { j } \; c ) / d _ { j } \bmod ( m _ { j } / d _ { j } ) .
$$

**7.** [题目](../sec-4-3-2.md#ex-4-3-2-7) 根据 $(23)(25)(26)$, 可得 $v _ { j } m _ { j - 1 } \ldots m _ { 1 } \equiv u _ { j } - ( v _ { j - 1 } m _ { j - 2 } \ldots m _ { 1 } + \cdots + v _ { 1 } )$ 以及 $C _ { j } m _ { j - 1 } \dots m _ { 1 } \equiv 1$ (modulo mj). 见保罗·普里查德, CACM 27(1984), 57.

通过改写公式, 这种方法在所做的算术运算次数相同的情况下, 使用的常数较少. 然而, 只有将模数按 $m _ { 1 } < m _ { 2 } < \dots < m _ { r }$ 排序时, 所使用的常数才会较少, 否则的话, 我们需要使用由 $m _ { i }\bmod m_{j}$ 的值构成的表. 相对于 $m _ { 1 } > m _ { 2 } > \cdots > m _ { r }$ 的排序方式, 上述排序方式所需的计算量更大. 这是因为模 $m_{r}$ 的运算所需计算量比模 $m_{1}$ 的计算要多得多. 但由于 $v _ { j }$ 的值跟 $m _ { j } - 1$ 差不多大, 所以在 $\left( 24 \right)$ 中取 $m _ { 1 } < m _ { 2 } < \cdots < m _ { r }$ 是比较明智的. 综上所述, 这种做法比正文中的公式更好, 尽管 4.3.3B 小节告诉我们, 当模数按 (14) 取值时使用正文中的公式比较好.

**13.** [题目](../sec-4-3-2.md#ex-4-3-2-13) (a) 当 $p = 2$ 和 5 时, $x^{2}-x=(x-1)x\equiv0\left(\bmod10^{n}\right)$ 等价于 $(x - 1)x \equiv 0 \pmod{p^n}$. 由于 $x$ 和 x-1 中必有一个是 $p$ 的倍数, 所以另一个与 $p^{n}$ 互素. 因此 x 和 x-1 中必有一个是 $p^{n}$ 的倍数. 当 $x \bmod 2^n = x \bmod 5^n = 0$ 或 1 时, 可得 $x \bmod 10^n = 0$ 或 1. 所以由自守性得 $x \bmod 2 ^ { n } \neq x \bmod 5 ^ { n } .$ (b) 如果 $x = qp^{n} + r$, 其中 $r \equiv 0$ 或 1, 则 $r \equiv r ^ { 2 } \equiv r ^ { 3 }$, 所以 $3 x ^ { 2 }   -   2 x ^ { 3 } \equiv ( 6 q p ^ { n } r   +   3 r )   -   ( 6 q p ^ { n } r   +   2 r ) \equiv r\ (\text{modulo }p ^ { 2 n })$.
