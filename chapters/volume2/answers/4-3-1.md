**A2′.** [将数字按位相加.] 置

$$

**4.** [题目](../sec-4-3-1.md#ex-4-3-1-4) 在执行步骤 A1 之前可断言: “$n\ge1$, 且对 $0\le i<n$ 有 $0\le u_i,v_i<b$.” 在执行步骤 A2 之前可断言: “$0\le j<n$, 对 $0\le i<n$ 有 $0\le u_i,v_i<b$, 对 $0\le i<j$ 有 $0\le w_i<b$, $0\le k\le1$, 以及 $(u_{j-1}\ldots u_0)_b+(v_{j-1}\ldots v_0)_b=(kw_{j-1}\ldots w_0)_b$.” 更确切地说, 最后这个等式的意义是

$$
\sum_{0\le l<j}u_lb^l+\sum_{0\le l<j}v_lb^l=kb^j+\sum_{0\le l<j}w_lb^l.
$$

在执行步骤 A3 之前可断言: “$0\le j<n$, 对 $0\le i<n$ 有 $0\le u_i,v_i<b$, 对 $0\le i\le j$ 有 $0\le w_i<b$, $0\le k\le1$, 以及 $(u_j\ldots u_0)_b+(v_j\ldots v_0)_b=(kw_j\ldots w_0)_b$.” 在执行步骤 A3 后可断言, 对 $0\le i<n$ 有 $0\le w_i<b$, $0\le w_n\le1$, 并且 $(u_{n-1}\ldots u_0)_b+(v_{n-1}\ldots v_0)_b=(w_n\ldots w_0)_b$.

只要证明上述各结论, 以及证明算法必定结束, 就可以完成证明.

**7.** [题目](../sec-4-3-1.md#ex-4-3-1-7) 以 $j = n - 3$ 为例. 当 $k =0$ 时概率为 $(b + 1) / 2b$, 当 $k =1$ 时概率为 $\left( \left( b - 1 \right) / 2 b \right) \left( 1 - 1 / b \right)$ 1 是发生进位且前一位数字不等于 b-1 的概率, 当 $k=2$ 时概率为 $\left( ( b - 1 ) / 2 b \right) ( 1 / b ) ( 1 - 1 / b )$, 当 $k=3$ 时概率为 $( ( b - 1 ) / 2 b ) ( 1 / b ) ( 1 / b ) ( 1 )$. 对固定的 k, 我们可将 j 从 n—1 到 0 的各概率值相加, 得出向前 进 k 位的平均次数为

$$
m _ { k } = \frac { b - 1 } { 2 b ^ { k } } \left( ( n + 1 - k ) \left( 1 - \frac { 1 } { b } \right) + \frac { 1 } { b } \right).
$$

作为对上述结论的检验, 我们由上式推出进位的平均次数为

$$
m _ { 1 } + 2 m _ { 2 } + \cdots + n m _ { n } = \frac { 1 } { 2 } \left( n - \frac { 1 } { b - 1 } \left( 1 - \left( \frac { 1 } { b } \right) ^ { n } \right) \right)   ,
$$

这与式 (6) 是一致的.

**28.** [题目](../sec-4-3-1.md#ex-4-3-1-28) 为方便起见, 我们假设 $v$ 的小数点在左侧, 即 $v = ( v _ { n } . v _ { n - 1 } v _ { n - 2 } \dots ) _ { b }$. 执行完步骤 N1 后有 $\textstyle \frac { 1 } { 2 } \leq v < 1 + 1 / b$: 因为

$$
v \left\lfloor \frac{b + 1}{v_{n - 1} + 1} \right\rfloor \leq \frac{v(b + 1)}{v_{n - 1} + 1} = \frac{v(1 + 1/b)}{(1/b)(v_{n - 1} + 1)} < 1 + \frac{1}{b},
$$

并且

$$
v \left\lfloor \frac{b + 1}{v_{n - 1} + 1} \right\rfloor \geq \frac{v(b + 1 - v_{n - 1})}{v_{n - 1} + 1} \geq \frac{1}{b} \frac{v_{n - 1}(b + 1 - v_{n - 1})}{v_{n - 1} + 1}.
$$

后一个数值在 $v_{n-1}=1$ 时达到极小, 因为它是凹函数且另一个极值较大.

步骤 N2 中的公式可写成 $v \leftarrow \left\lfloor\frac{b(b+1)}{v_{n-1}+1}\right\rfloor\frac vb$, 因此像上一段那样可推知 v 必定小于 $1 + 1 / b .$

如果 $t = v_{n - 1} + 1$, 则执行完一次步骤 N2 后 v 的最小值不小于

$$
\begin{aligned}\left( \frac{b(b+1)-v_{n-1}}{v_{n-1}+1} \right) \frac{v}{b} \geq \left( \frac{b(b+1)-v_{n-1}}{v_{n-1}+1} \right) \frac{v_{n-1}}{b^2} &= \left( \frac{b(b+1)+1-t}{t} \right) \left( \frac{t-1}{b^2} \right) \\&= 1 + \frac{1}{b} + \frac{2}{b^2} - \frac{1}{b^2} \left( t + \frac{b(b+1)+1}{t} \right).\end{aligned}
$$

当 $t = b / 2 + 1$ 时这个量达到最小值, 其下界为 $1 - 3 / 2 b .$ 所以执行完一次步骤 N2 后 $v _ { n - 1 } \geq b - 2 .$ 最后, 当 $b \geq 5$ 时有 $(1 - 3/2b)(1 + 1/b)^{2} > 1$, 所以最多再执行两次步骤 N2 即可. 当 $b<5$ 时结论是容易验证的.
