**1.** [题目](../sec-4-6-2.md#ex-4-6-2-1) 对任意选取的 $k \leq n$ 个不同的根, 存在 $p^{n-k}$ 个首一多项式以所选各根为根 (每个至少一次). 所以根据容斥原理 (1.3.3 节), 没有一次因子的多项式的个数是 $\textstyle \sum _ { k \leq n } { \binom { p } { k } } p ^ { n - k } ( - 1 ) ^ { k }$, 这个数值交替地小于等于和大于等于这个级数的部分和. 习题中所给的上下界分别对应于 $k \leq 2$ 和 $k \leq 3$ 的情形. 当 $n \geq p$ 时, 多项式至少有一个线性因子的概率是 $1 - (1 - 1 / p)^{p}$. 线性因式的平均数目等于 p 乘以 $x$ 可整除 $u ( x )$ 的次数, 即 $\begin{array} { r } { 1 + p ^ { - 1 } + \cdots + p ^ { 1 - n } = \frac { p } { p - 1 } ( 1 - p ^ { - n } ) } \end{array}$

[通过类似的方式可推导出存在一个不可约二次因子的概率是 $1-\textstyle\sum_{0\le k\le n/2} \binom { p ( p - 1 ) / 2 } { k } ( - 1 ) ^ { k } p ^ { - 2 k }$. 当 $n \geq 2$ 时这个概率值介于 $\frac{3}{8} - \frac{1}{4}p^{-1}$ 和 $\frac{1}{2} - \frac{1}{2}p^{-1}$ 之间, 并且当 $n \to \infty$ 时趋向于 $1 - e^{-1/2}(1 + \frac{1}{2}p^{-1}) + O(p^{-2})$. 这样的因子的平均数目为 $\frac{1}{2}-\frac{1}{2}p^{-2\left \lfloor n/2 \right \rfloor }$.]

注记: 任取固定的整系数多项式 $u ( x )$. 温伯格发现, 如果 $u ( x )$ 在整数集上不可约, 则 $u ( x )$ 模 p 的线性因子的平均数目当 $p \to \infty$ 时趋向于 1. 这是因为 $u ( x )$ 的伽罗瓦群是可传递的, 并且在任意可传递的置换群中随机选取的元素的 1-循环的平均数目为 1. 由此可知, 当 $p \to \infty$ 时, $u(x)$ 模 p 的线性因子的平均数目等于 u(x) 在整数集上的不可约因子的数目. [见习题 37 的答案中的说明, 以及 Proc. Symp. PureMath. 24 (Amer. Math. Soc., 1972), 321–332. ]

**15.** [题目](../sec-4-6-2.md#ex-4-6-2-15) 可假设 $u \neq 0$ 且 $p$ 是奇数. 对多项式 $x ^ { 2 } - u$ 使用伯利坎普的算法, 可知存在平方根当且仅当 $Q-I=0$ 当且仅当 $u^{(p-1)/2} \bmod p = 1$. 不过这是我们已经知道的结论. 由坎托和察森豪斯的方法知, $\gcd(x^{2}-u,(sx+t)^{(p-1)/2}-1)$ 通常是非平凡因子. 确实能证明通过取 $(p - 1)/2 + (0,1$ 或 2) 个 $s$ 的值可以找到非平凡因子. 实际计算中, 按顺序取值和随机取值的效果差别不大, 因此我们给出以下算法: “依次求 $\operatorname* { g c d } ( x ^ { 2 } - u , x ^ { ( p - 1 ) / 2 } - 1 ) ,   \operatorname* { g c d } ( x ^ { 2 } - u , ( x + 1 ) ^ { ( p - 1 ) / 2 } - 1 ) ,   \operatorname* { g c d } ( x ^ { 2 } - u , ( x + 2 ) ^ { ( p - 1 ) / 2 } - 1 ) ,   \ldots$, 直到找到第一个形如 $x+v$ 的最大公因子. 则 $\sqrt { u } \equiv \pm v .$ ” 当 $p$ 的值很大时, (对随机选取的 s) 预期的运行时间是 $O ( \operatorname { l o g } p ) ^ { 3 }$
