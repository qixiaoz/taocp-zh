**4.** [题目](../sec-4-5-4.md#ex-4-5-4-4) 按照习题 3.1-11 的记号,

$$
\sum _ { \mu , \lambda } 2 ^ { \lceil \lg \max ( \mu + 1 , \lambda ) \rceil } P ( \mu , \lambda ) = \frac { 1 } { m } \sum _ { l \geq 1 } f ( l ) \prod _ { k = 1 } ^ { l - 1 } \left( 1 - \frac { k } { m } \right) ,
$$

其中 $\begin{array} { r } { f ( l ) = \sum _ { 1 \leq \lambda \leq l } 2 ^ { \lceil \lg\max ( l + 1 - \lambda , \lambda ) \rceil } } \end{array}$. 如果 $l = 2 ^ { k + \theta }$, 其中 $0 < \theta \leq 1$, 则

$$
f ( l ) = l ^ { 2 } ( 3 \cdot 2 ^ { - \theta } - 2 \cdot 2 ^ { - 2 \theta } ) ,
$$

其中函数 $3 \cdot 2 ^ { - \theta } - 2 \cdot 2 ^ { - 2 \theta }$ 在 $\theta = \lg(4/3)$ 时达到极大值 $\frac{9}{8}.$, 在 $\theta = 0$ 和 1 时达到极小值 1. 因此 $2 ^ { \lceil \lg\max ( \mu + 1 , \lambda ) \rceil }$ 的平均值介于 $\mu+\lambda$ 的平均值的 1.0 倍和 1.125 倍之间, 从而结论得证.

注记: 布伦特已经发现当 $m \to \infty$ 时, 密度 $\Pi_{k = 1}^{l - 1}(1 - k/m) = \exp(-l(l - 1)/2m + O(l^3/m^2))$ 趋向于一个正态分布, 且可假设θ是均匀分布的. 因此 $3 { \cdot } 2 ^ { - \theta } - 2 { \cdot } 2 ^ { - 2 \theta }$ 的平均值为 $3/(4\ln2)$, 而算法 B 所需的迭代次数近似为 $( 3 / ( 4 \ln 2 ) + { \textstyle { \frac { 1 } { 2 } } } ) \sqrt { \pi m / 2 } \approx 1 . 9 8 2   7 7 \sqrt { m } .$ 对在习题 3.1-7 的解答中给出的更一般的算法, 我们可做类似的分析得到近似值 $1.926 00\sqrt{m}$, 其中 “理想地” 取 p 为 $( p ^ { 2 } - 1 ) \ln p = p ^ { 2 } - p + 1$ 的根 $p \approx 2 . 4 7 7   1 3 6   6 .$ 见 BIT 20(1980), 176–184.

算法 B 是波拉德的原始算法的进一步细化, 它源于习题 3.1-6(b) 而不是当时还未被发现的习题 3.1-7 的结论. 他证明了使得 $X _ { 2 n } = X _ { n }$ 最小的 n 的近似平均值为 $( \pi ^ { 2 } / 1 2 ) Q ( m ) \approx 1 . 0 3 0 8 \sqrt { m }$ 式 4.5.3-(21) 解释了常数 $\pi^{2}/12$ 的来由. 因此他的原始算法的平均工作量约为 $1.030 81\sqrt{m}$ 次求最大公因数 (或模 m 乘法) 加上 $3.092 43\sqrt{m}$ 次平方运算. 当求最大公因数的代价超过平方运算的大约 1.17 倍时 (对于非常大的数一般就会出现这种情况) 这个算法的表现比算法 B 更好.

然而, 布伦特注意到, 我们可以通过对 $k > l / 2$ 的情形不检查最大公因数来改进算法 B. 如果反复执行步骤 B4 直至 $k \leq l / 2$, 则再进行 $\lambda \lfloor \ell ( \mu ) / \lambda \rfloor = \ell ( \mu ) - ( \ell ( \mu ) \bmod \lambda )$ 次迭代后仍可检测到循环. 此时平均工作量为求平方时不求最大公因数的约 $( 3 / ( 4 \ln 2 ) ) \sqrt { \pi m / 2 } \approx 1 . 3 5 6 \: 1 1 \sqrt { m }$ 次迭代加上求平方时也求最大公因数的 $( ( \ln \pi - \gamma ) / ( 4 \ln 2 ) + { \textstyle { \frac { 1 } { 2 } } } ) \sqrt { \pi m / 2 } \approx . 8 8 3 \: 1 9 \sqrt { m }$ 次迭代. 见科昂的分析, A Course inComputational Algebraic Number Theory (Berlin: Springer, 1993), §8.5. ]

**6.** [题目](../sec-4-5-4.md#ex-4-5-4-6) 我们来统计一下同余式 $N \equiv (x - y)(x + y)\ (\text{modulo }p)$ 的满足 $0 \leq x, y < p$ 的解 (x,y) 的数目. 由于 $N \not\equiv 0$ 且 $p$ 是素数, 所以 $x + y \not\equiv 0.$ 对任一 $v \not \equiv 0$, 存在唯一的 u$(\text{modulo }p)$ 使得 $N \equiv u v .$ 由于 $p$ 是奇数, 因此由同余式 $x - y \equiv u$ 和 $x+y\equiv v$ 可唯一确定 $x\bmod p$ 和 $y\bmod p$. 所以题中所述的同余式恰有 p-1 个解 (x,y). 如果 (x,y) 是解, 那么当 $y \neq 0$ 时 (x,p-y) 也是解, 因为有 $(p - y)^{2} \equiv y^{2}$. 此

**8.** [题目](../sec-4-5-4.md#ex-4-5-4-8) (可假设 N=2M 为偶数.) 下面的算法使用了辅助表 X[1], $X[2] , \; \ldots , \; X [ M - 1 ]$, 其中 $X[k]$ 用于标记 2k+1 是否为素数.

S1. 对 $1 \leq k < M ,$ 置 $X[k] \leftarrow 1$, 并且置 $j \leftarrow 1 , ~ k \leftarrow 1 , ~ p \leftarrow 3 , ~ q \leftarrow 4 .$ (在此算法执行期间 $p=2j+1$, $q=2j+2j^2$. )

S2. 如果 $X[j] = 0$, 则转向 S4. 否则输出 p (它是素数), 并且置 $k \leftarrow q .$

S3. 如果 $k < M$, 则置 $\begin{array} { l } { X [ k ] \leftarrow 0 , \: k \leftarrow k + p , } \end{array}$, 并重复执行这一步骤.

S4. 置 $j \leftarrow j + 1,\ p \leftarrow p + 2,\ q \leftarrow q + 2p - 2.$ 如果 $j<M$, 则回到 S2. ■

如果在步骤 S4 中比较 q (而不是 j) 和 M 的大小, 并且增加一个循环对所有剩下的等于 1 的 $X[j]$ 输出 $2 j + 1$, 以减少对 p 和 q 的操作次数, 则此计算过程的主要部分的执行速度可明显提高.

注记: 尼科马彻斯在其著作中介绍了埃拉托色尼的原始筛法 [IntroductiontoArithmetic, 卷 1, 第 13 章]. 众所周知 $\textstyle \sum _ { p \operatorname { p r i m e } } [ p   \leq   N ] / p = \operatorname { l n } \operatorname { l n } N   +   M   +   O \big ( ( \operatorname { l o g } N ) ^ { - 1 0 \: 0 0 0 } \big )$, 其中 $\begin{array} { r } { M = \gamma + \sum _ { k \geq 2 } \mu ( k ) \ln \zeta ( k ) / k } \end{array}$ 是默滕斯常数 $0 . 2 6 1 4 9   7 2 1 2 8   4 7 6 4 2   7 8 3 7 5   5 4 2 6 8   3 8 6 0 8   6 9 5 8 5   9 0 5 1 6 - .$ 见默滕斯, Crelle 76(1874), 46-62; 丹尼尔·格林和高德纳, Mathematics for the Analysis of Algorithms (Boston: Birkhäuser, 1981), §4.2.3. 特别地, 尼科马彻斯所描述的原始算法的运算次数为 $N\ln\ln N+O(N)$. 在习题 5.2.3-15 和 7.1.3 节中讨论了用于生成素数的筛法的效率方面的改进.

**15.** [题目](../sec-4-5-4.md#ex-4-5-4-15) $U_{n}=(a^{n}-b^{n})/\sqrt{D}$, 其中 $a = \frac{1}{2}(P + \sqrt{D})$ $b = \frac{1}{2}(P - \sqrt{D})$ $D = P^{2} - 4Q.$ 所以 $2^{n - 1}U_{n} =$ $\textstyle \sum _ { k } { \binom { n } { 2 k + 1 } } P ^ { n - 2 k - 1 } D ^ { k }$. 从而当 $p$ 是奇素数时 $U_{p} \equiv D^{(p - 1)/2}\ (\text{modulo }p)$. 类似地, 如果 $V_{n}=a^{n}+b^{n}=$ $U _ { n + 1 } - Q U _ { n - 1 }$, 则 $2^{n - 1}V_{n} = \sum_{k}\binom{n}{2k}P^{n - 2k}D^{k}$, 且 $V_{p} \equiv P^{p} \equiv P.$ 因此, 如果 $U_{p} \equiv -1$, 则我们得到 $U _ { p + 1 } \bmod p = 0 .$ 如果 $U_{p} \equiv 1$, 则得到 $( Q U _ { p - 1 } ) \bmod p = 0 .$ 这里如果 $Q$ 是 $p$ 的倍数, 则对于 $n>0$ 有 $U _ { n } \equiv P ^ { n - 1 } \; (\text{modulo }p)$, 所以 $U_{n}$ 绝对不可能是 $p$ 的倍数. 如果 $Q$ 不是 $p$ 的倍数, 则 $U_{p-1} \bmod p = 0 .$ 于是像在定理 L 中那样, 如果 $N = p _ { 1 } ^ { e _ { 1 } } \ldots p _ { r } ^ { e _ { r } } , \quad N \perp Q , \quad t = \operatorname { l c m } _ { 1 \leq j \leq r } ( p _ { j } ^ { e _ { j } - 1 } ( p _ { j } + \epsilon _ { j } ) )$, 则 $U_{t}\bmod{N}=0.$ 在本习题的假设下, N 的幻秩为 N+1. 因此 N 与 $Q$ 互素, 且 t 是 $N + 1$ 的倍数, 此外, 由假设条件也可推导出每个 $p_{j}$ 都是奇数, 每个 $\epsilon _ { j }$ 都等于±1, 所以 $\begin{array} { r } { t \leq 2 ^ { 1 - r } \prod p _ { j } ^ { e _ { j } - 1 } (p_j+\tfrac13p_j) = 2 ( \frac { 2 } { 3 } ) ^ { r } N . } \end{array}$ 于是 $r = 1 , \quad t = p _ { 1 } ^ { e _ { 1 } } + \epsilon _ { 1 } p _ { 1 } ^ { e _ { 1 } - 1 }$. 最后, 因此得到 $e _ { 1 } = 1$ 和 $\epsilon _ { 1 } = 1$

论据 2. 给定满足 $a \perp n$ 的 a 和 n, 对所有 $b \perp n$ 解的数目都是相同的. 这个结论由提示中所给的恒等式以及论据 1 就可推导出, 因为如果 $x_{1}^{2}-ay_{1}^{2}\equiv b$, 当 $( x _ { 2 } , y _ { 2 } )$ 取遍 $x^{2}-ay^{2}\equiv 1$ 的所有解, $(x_1x_2+ay_1y_2,x_{1}y_{2}+x_{2}y_{1})$ 就取遍 $x^{2}-ay^{2}\equiv b$ 的所有解, 换句话说, 当 $x_{1}^{2}-ay_{1}^{2}\perp n$ 时, $(x_{2},y_{2})$ 由 $( x _ { 1 } , y _ { 1 } )$ 以及 (x,y) 唯一确定.

论据 3. 给定满足 $z ^ { 2 } \equiv a \pmod{s}$ 的整数 $( a , s , z )$, 我们可以找到整数 $( x , y , m , t )$ 满足 $x^{2} - a y^{2} = m^{2} s t$, 其中 $(x,y) \ne (0,0)$ 且 $t ^ { 2 } \leq \frac { 4 } { 3 } | a |$. 事实上, 如果 $z^{2} = a + ms$, 可令 $( u , v )$ 为使得 $(zu + mv)^{2} + |a|u^{2}$ 达到最小值的非零整数对. 利用 3.3.4 节中的方法可以很快求出 $( u , v )$, 并且由习题 3.3.4-9 可推导出 $(zu + mv)^{2} + |a|u^{2} \le |m|(\tfrac43|a|)^{1/2}$. 因此 $(zu + mv)^{2} - au^{2} = mt$, 其中 $\textstyle t ^ { 2 } \leq \frac { 4 } { 3 } | a |$ 于是提示中的恒等式给出 $x^{2}-ay^{2}=(ms)(mt)$ 的解.
