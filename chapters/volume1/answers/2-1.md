4\. <a id="ans-2-1-4"></a>[习题](../sec-2-1.md#ex-2-1-4)  C1. 置 X ←LOC(TOP). 5\. <a id="ans-2-1-5"></a>[习题](../sec-2-1.md#ex-2-1-5)  D1. 置 X←LOC(TOP), Y ←TOP. (见上面的步骤 C1. 根据假设, $\mathtt { Y } \neq \Lambda .$ 在接下来的整个算法中, X 始终紧跟在 Y 之后一步, 即 $\mathbb { Y } = \mathbb { N } \mathbb { E } \mathbb { T } \left( \mathbb { X } \right)$.)D2. 如果 $\mathrm{NEXT}(Y) \neq \Lambda$, 则置 X ←Y,Y←NEXT(Y), 并重复此步. D3. (现在, NEXT(Y) =Λ, 因此 Y 指向底部的牌, X 指向底部第二张牌.) 置 NEXT(X)←Λ, NEWCARD ← Y.
