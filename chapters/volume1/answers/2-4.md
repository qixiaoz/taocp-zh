4\. <a id="ans-2-4-4"></a>[习题](../sec-2-4.md#ex-2-4-4) (怀斯的解答) 规则 (c) 违反, 当且仅当有一个数据项的完备限定 $A _ { 0 } \mathtt { O F } \dots \mathtt { O F } A _ { n }$ 也是对另一数据项的 COBOL 引用. 因为其父母 $A_1\;\mathtt{OF}\;\ldots\;\mathtt{OF}\;A_n$ 必须也满足规则 (c), 我们可以假定引用的另一数据项是同一父母的后代. 因此, 可以扩充算法 A, 检测加入数据表的每个新数据项的父母是否是其他同名项的祖先, 并检查其他同名项的父母是否在栈中. (当该父母项为Λ时, 它是所有项的祖先并总是在栈上).

9\. <a id="ans-2-4-9"></a>[习题](../sec-2-4.md#ex-2-4-9)  如果 $\alpha$ 和 $\beta$ 都不是基本项, 则 “MOVE CORRESPONDING $\alpha$ TO $\beta ^ { \prime \prime }$ 等价于遍取组 $\alpha$ 和 $\beta$ 中共用名字 A 的语句 “MOVE CORRESPONDING A OF $\alpha\ \mathtt{TO}\ A\ \mathtt{OF}\ \beta\text{”}$ 的集合. (正文中给出的 “MOVECORRESPONDING” 的传统定义较为繁琐, 这种叙述方式则更为优雅). 可以归纳证明, 步骤 C2 到 C5 将最终终止于 $\mathtt { P } = \mathtt { P } \mathtt { O }$ 和 $\mathbb{Q} = \mathbb{Q}0$, 从而验证算法 C 满足这个定义. 证明细节像以前在 “树的归纳” 中做过多次的那样进行填充 (例如, 参见算法 2.3.1T 的证明).

(b) 置 $\mathtt { P 1 } \leftarrow \mathtt { P }$, 然后置 $\mathtt{P1}\leftarrow\mathtt{PREV}(\mathtt{P1})$ 零次或多次, 直到 $\mathtt{PREV}(\mathtt{P1})=\Lambda$; 对变量 Q1 和 Q 进行类似操作; 然后测试是否 P1=Q1. 或者, 如果数据表条目是有序的, 对所有 P 有 $\mathtt{PREV}(\mathtt P)<\mathtt P$, 则依赖于是否有 $P > Q$, 沿较大条目的 PREV 链看是否能遇到较小条目, 显然可以更快完成测试.

11\. <a id="ans-2-4-11"></a>[习题](../sec-2-4.md#ex-2-4-11)  增加一个新的链字段 $\mathtt { S I B I ( P ) } \equiv \mathtt { C H I L D ( P A R E N T ( P ) ) }$, 可以将步骤 C4 的速度提高一点点. 更有意义的是, 可以修改 CHILD 和 SIB 链, 使得 NAME(SIB(P))>NAME(P), 从而显著提高步骤 C3 中搜索的速度, 因为仅需扫描每个家族一趟就能找到匹配的成员. 因此这一修改将去掉算法 C 中仅有的 “搜索”. 对于这一解释, 算法 A 和 C 很容易修改, 读者不妨练习一番. (但是, 考虑到 MOVECORRESPONDING 语句的相对频率以及家族组的常规大小, 在真正的 COBOL 程序翻译中, 其实并不会得到大幅加速.)

14\. <a id="ans-2-4-14"></a>[习题](../sec-2-4.md#ex-2-4-14) 下面的算法使用一个辅助栈, 步骤编号与正文中的算法直接对应.

C1'. 置 $\mathtt{P}\leftarrow \mathtt{P0},\quad \mathtt{Q}\leftarrow \mathtt{Q0}$, 并置栈内容为空.  
C2'. 若 SCOPE(P) = P 或 $\mathtt{SCOPE}(\mathtt Q)=\mathtt Q$, 则输出 (P,Q) 作为所求偶对之一, 并转到 C5'否则, 让 (P,Q) 人栈, 并置 $\mathbb{P} \leftarrow \mathbb{P} + 1, \mathbb{Q} \leftarrow \mathbb{Q} + 1.$   
C3'. 确定 P 和 Q 是否指向同名条目 (见习题 10(b)). 如果是, 则转到 C2'. 不是, 则令 (P1,Q1) 为栈顶条目; 若 $\mathtt{SCOPE}(\mathtt{Q})<\mathtt{SCOPE}(\mathtt{Q1})$, 则置 $\bar{\mathbb{Q}} \leftarrow \mathrm{SC0PE(Q)} + 1$ 并重复步骤 C3'.  
C4'. 令 (P1,Q1) 为栈顶条目. 若 $\mathtt { S C O P E ( P ) } < \mathtt { S C O P E ( P 1 ) }$, 则置 $\mathtt{P}\leftarrow \mathtt{SCOPE}(\mathtt{P})+1,\quad \mathtt{Q}\leftarrow \mathtt{Q1}+1$, 并转到 C3'. 若 $\mathtt { S C O P E ( P ) } = \mathtt { S C O P E ( P 1 ) }$, 则置 P←P1,Q←Q1, 删除栈顶条目.  
C5'. 若栈为空, 则算法终止. 否则, 转到 C4.
