2\. <a id="ans-1-2-11-1-2"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-2)  每个大记号表示一个不同意义的近似量. 由于左端可以取 $f(n)-(-f(n))=2f(n)$, 所以最恰当的说法是 $O(f(n)) - O(f(n)) = O(f(n))$, 这是由 (6) 和 (7) 推出的. 为证明 (7), 注意如果对于 $n \geq n _ { 0 }$ 有 $\lvert x_n\rvert\le M\lvert f(n)\rvert$, 对于 $n \geq n _ { 0 } ^ { \prime }$ 有 $\lvert x'_n\rvert\le M'\lvert f(n)\rvert$, 那么对于 $n\ge\max(n_0,n'_0)$ 有 $| x _ { n } \pm x _ { n } ^ { \prime } | \leq | x _ { n } | + | x _ { n } ^ { \prime } | \leq ( M + M ^ { \prime } ) | f ( n ) |$. (署名乔纳森·奎克, 学生是也.)

5\. <a id="ans-1-2-11-1-5"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-5)  如果 $f(n)=n^{2},\ g(n)=1$, 那么 n 属于集合 $\bar{O}(f(n) + g(n))$, 但不属于集合 $f(n) + O(g(n))$. 所以命题不成立.

6\. <a id="ans-1-2-11-1-6"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-6)  错在用一个大 O 记号代替 n 个大 O 记号, 而 $n$ 是一个可变的数量, 因此错误地暗指 M 的单个值就能满足每一项 $| k n | \leq M n .$ 如我们所知, 给定的和实际为 $\Theta ( n ^ { 3 } )$. 最后的等式 $\begin{array} { l } \sum _ { k = 1 } ^ { n } O ( n ) = O ( n ^ { 2 } ) \end{array}$ 是完全正确的.

7\. <a id="ans-1-2-11-1-7"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-7) 如果 $x$ 为正数, 幂级数 1.2.9-(22) 表明 $e^{x} > x^{m + 1} / (m + 1)!$; 因此 $e ^ { x } / x ^ { m }$ 的比值不以任何 M 为界.  
8\. <a id="ans-1-2-11-1-8"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-8)  把 n 换成 $e ^ { n }$, 应用上题的方法.

9\. <a id="ans-1-2-11-1-9"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-9)  如果 $\lvert f(z)\rvert\le M\lvert z\rvert^m$ 对于 $| z | \leq r$ 成立, 那么 $| e ^ { f ( z ) } | \leq e ^ { M | z | ^ { m } } = 1 + | z | ^ { m } ( M + M ^ { 2 } | z | ^ { m } / 2 ! +$ $M ^ { 3 } | z | ^ { 2 m } / 3 ! + \cdots ) \leq 1 + | z | ^ { m } ( M + M ^ { 2 } r ^ { m } / 2 ! + M ^ { 3 } r ^ { 2 m } / 3 ! + \cdots ) .$

10\. <a id="ans-1-2-11-1-10"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-10)  $\ln (1 + O(z^m)) = O(z^m)$, 如果 $m$ 是正整数. 证明: 如果 $f(z) = O(z^m)$, 那么存在正整数 $r < 1$ 和 $r ^ { \prime } < 1$, 以及合适的常数 M, 使得 $\lvert z\rvert\le r$ 时有 $|f(z)| \leq M|z|^m \leq r'.$ 于是 $\left| \ln(1 + f(z)) \right| \leq$ $\lvert f(z)\rvert+\tfrac12\lvert f(z)\rvert^2+\cdots\le\lvert z\rvert^m M(1+\tfrac12r'+\cdots)$

11\. <a id="ans-1-2-11-1-11"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-11)  我们可以应用等式 (12), 取 $m =1$ 和 $z = \operatorname { l n } n / n .$ 这是合理的, 因为当 $n$ 充分大时, 对于任何给定的 $r > 0$, 有 $\operatorname { l n } n / n \leq r .$

12\. <a id="ans-1-2-11-1-12"></a>[习题](../sec-1-2-11-1.md#ex-1-2-11-1-12)  令 $f(z) = \left(ze^{z}/(e^{z} - 1)\right)^{1/2}$ 如果 $\left[ \begin{matrix} { 1 / 2 } \\ { 1 / 2 - k } \\ \end{matrix} \right]$ 是 $\mathcal { O } ( n ^ { k } )$, 所述恒等式证明 $\left[ z ^ { k } \right] f ( z ) = O ( n ^ { k } / ( k - 1 ) ! )$ 所以当 z = 2πi 时 f(z) 会收敛. 但是 $f(2\pi i) = \infty.$
