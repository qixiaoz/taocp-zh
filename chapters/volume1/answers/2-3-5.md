1\. <a id="ans-2-3-5-1"></a>[习题](../sec-2-3-5.md#ex-2-3-5-1) 表结构是一个有向图, 其中从每个顶点出来的弧是有序的, 一些出度为 0 的顶点被指定为 “原子”. 此外, 存在一个顶点 S, 使得对于所有的顶点 $V \neq S$, 都存在一条从 S 到 V 的定向路径. (逆转弧的方向, S 将为 “根”.)

3\. <a id="ans-2-3-5-3"></a>[习题](../sec-2-3-5.md#ex-2-3-5-3)  正如正文中所提到的, 我们还要证明算法终止时 P=PO. 如果只有 PO 待标记, 算法肯定正确. 如果 $n>1$ 个结点待标记, 则一定有 ATOM(PO)=0. 于是, 步骤 E4 置 ALINK(PO)←Λ, 并且以 ALINK(PO) 替换 PO,PO 替换 T 执行该算法. 根据归纳法可知 (注意, 由于 MARK(PO) 现在等于 1, 根据步骤 E4 和 E5, 所有指向 PO 的链都等价于 A), 最终我们将标记从 ALINK(PO) 出发并且不经过 PO 的所有路径上的所有结点, 到达步骤 E6 时将有 T =PO,P =ALINK(PO). 由于 ATOM(T)=1, 因此步骤 E6 恢复 ALINK(PO) 和 ATOM(PO), 并且回到步骤 E5. 步骤 E5 置 BLINK(PO)←Λ等, 重复类似的论证, 可以证明, 最终将标记从 BLINK(PO) 出发并且不经过 PO 或从 ALINK(PO) 可达的结点的所有路径上的所有结点. 然后, 到达步骤 E6 时将有 T=PO,P=BLINK(PO), 最后一次到达 E6 时则有 T=Λ,P=PO.

10\. <a id="ans-2-3-5-10"></a>[习题](../sec-2-3-5.md#ex-2-3-5-10)  Z1.[初始化. ] 置 F ← PO,R⇐ AVAIL,NODE(R) ← NODE(F), REF(F) ← R. (这里, F 和 R 是指针, 指向在遇到的所有表头结点的 REF 字段中建立的队列.)

Z2.[开始一个新表.] 置 $\mathtt{P}\leftarrow \mathtt{F},\quad \mathtt{Q}\leftarrow \mathtt{REF}(\mathtt{P}).$

Z3. [向右推进.] 置 P←RLINK(P). 如果 P =Λ, 则转到 Z6.

Z4.[复制一个结点.] 置 Q1⇐AVAIL,RLINK(Q)←Q1, Q←Q1,NODE(Q)←NODE(P).

Z5.[转换子表链接.] 如果 T(P)=1, 则置 P1←REF(P). 如果 REF(P1)=Λ, 则置 REF(R)←P1,R ⇐ AVAIL, REF(P1) ← R, NODE(R) ← NODE(P1), REF(Q) ← R. 如果 T(P) = 1 并且 $\mathtt{REF}(\mathtt{P1})\ne\Lambda$, 则置 REF(Q)←REF(P1). 转到 Z3.

Z6.[移到下一个表.] 置 RLINK(Q)←Λ. 如果 $\mathrm{REF}(\mathrm{F}) \neq \mathrm{R}$, 则置 F←REF(REF(F)), 并返回到 Z2. 否则, 置 REF(R)←Λ,P←PO.

Z7. [最后清理.] 置 Q←REF(P). 如果 $a \neq \Lambda$, 则置 REF(P)←Λ,P←Q, 并且重复步骤 Z7. 当然, 这样使用 REF 字段, 表在复制期间不能保持格式工整, 因此就不可能使用算法 D 完成垃圾回收. 人们已经设计了一些优雅的表移动和表复制算法, 它们对表的表示所做的假定弱得多. 见道格拉斯·克拉克, CACM19(1976), 352-354; 约翰·罗布森, CACM20(1977), 431-433.

11\. <a id="ans-2-3-5-11"></a>[习题](../sec-2-3-5.md#ex-2-3-5-11) 有一种笔算方法可以形式化地写出来作为答案: 首先, 对给定集合中的每个表都附以唯一的名字 (例如一个大写字母). 在这个例子中, 可以有 $A=(a\mathbin{:}C,b,a\mathbin{:}F)$, F = (b: D), B = (a: F, b, a: E), C= (b: G), G =(a: C), D =(a: F), E =(b: G). 现在, 构造一个列表, 列出每对必须证明它们相等的表名对. 逐次把这些表名对加到该列表中, 直到或者因为一对表名在第一层不一致而发现矛盾 (于是原来给定的表不相同), 或者该列表中的表名对不再蕴涵其他表名对 (于是原来给定的表相同). 在这个例子中, 该表名对列表开始仅包含给定的表名对 AB, 然后得到表名对 CF 和 EF (通过匹配 A 和 B), 此后加入 DG (由 CF), 于是得到一个自洽的集合.

为了证明这种方法的正确性, 指出三点: (i) 如果它返回的答案是 “不相同”, 则给定的表不相同; (ii) 如果给定的表不相同, 则它返回 “不相同”; (iii) 它总会终止.
