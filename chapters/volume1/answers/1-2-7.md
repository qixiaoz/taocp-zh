17\. <a id="ans-1-2-7-17"></a>[习题](../sec-1-2-7.md#ex-1-2-7-17) 第一种解法 (初等方法): 取 (p-1)! 作为分母, 这是真正分母的倍数, 但不是 $p$ 的倍数. 我们仅需证明, 对应的分子 $(p - 1)! / 1 + (p - 1)! / 2 + \cdots + (p - 1)! / (p - 1)$ 确实是 $p$ 的倍数. 以 p 为模, $(p - 1)! / k \equiv (p - 1)! k'$, 其中 $k ^ { \prime }$ 可以由关系式 $k k ^ { \prime } \bmod p = 1$ 确定. 集合 $\{1',2',\ldots,(p-1)'\}$ 正好是集合 $\{ \hat { 1 } , \: \hat { 2 } , \: \ldots , \: p - \hat { 1 } \}$, 所以分子与 $(p - 1)! \left(1 + 2 + \cdots + p - 1\right)$ 同余.

第二种解法 (高等方法): 由习题 4.6.2-6, 我们有 $x ^ { \bar { p } } \equiv x ^ { \bar { p } } - x { \mathrm { ~ ( m o d u l o ~ } } p { \mathrm { ) } }$. 因此, 由习题 1.2.6-32, $\genfrac{[}{]}{0pt}{}{p}{k}\equiv\delta_{kp}-\delta_{k1}\ (\text{modulo }p)$. 现在应用习题 6.

其实已经知道, 当 $p > 3$ 时, $H_{p - 1}$ 的分子是 $p^{2}$ 的倍数, 见哈代和爱德华·赖特的《哈代数论》[^cn403-1] 第 7.8 节 [ An Introduction to the Theory of Numbers ].
