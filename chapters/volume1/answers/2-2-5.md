#### 2.2.5 节

1\. <a id="ans-2-2-5-1"></a>[习题](../sec-2-2-5.md#ex-2-2-5-1)  左端插入 $\mathtt{Y}:\;\mathtt{P}\Leftarrow \mathtt{AVAIL};\quad \mathtt{INFO}(\mathtt{P})\leftarrow \mathtt{Y};\quad \mathtt{LLINK}(\mathtt{P})\leftarrow \Lambda ;\quad \mathtt{RLINK}(\mathtt{P})\leftarrow \mathtt{LEFT};$ 如果 $\mathrm{LEFT} \neq \Lambda$, 则 LLINK(LEFT) ← P else RIGHT ← P;LEFT ← P. 置 Y 为最左元素并删除: 如果 LEFT = Λ, 则下溢; P ← LEFT;LEFT ← RLINK(P); 如果 LEFT = Λ, 则 RIGHT ← Λ, 否则 LLINK(LEFT) ← Λ;Y ← INFO(P); $\mathtt{AVAIL}\Leftarrow \mathtt{P}.$

2\. <a id="ans-2-2-5-2"></a>[习题](../sec-2-2-5.md#ex-2-2-5-2) 考虑在同一端连续多次删除. 每次删除之后, 我们必须知道下一次要删除什么, 所以表中诸链的指向必须背离表的删除端. 因此, 在两端删除意味着两个方向必须都有链. 另一方面, 习题 2.2.4-18 解释了如何在单个链字段中表示两个链, 采用这种方法能实现一般的双端队列操作.

3\. <a id="ans-2-2-5-3"></a>[习题](../sec-2-2-5.md#ex-2-2-5-3)  为了证明 CALLUP 独立于 CALLDOWN, 例如, 注意在表 1 中, 在时间 0393-0444, 尽管第 2 层和第 3 层有人等待, 但电梯并没有停下; 这些人按了 CALLDOWN 键, 但是, 如果他们按的是 CALLUP 键, 电梯应该会停下.

为了证明 CALLCAR 独立于其他变量, 注意在表 1 中, 当门在时刻 1378 开始打开时, 电梯已经决定要 GOINGUP. 根据步骤 E2, 如果 $\mathtt{CALLCAR}[1]=\mathtt{CALLCAR}[2]=\mathtt{CALLCAR}[3]=\mathtt{CALLCAR}[4]=0$, 则电梯在该点的状态应改为 NEUTRAL, 但事实上, CALLCAR[2] 和 CALLCAR[3] 已经被电梯内的乘客 7 和 9 设置为 1. (如果我们想象相同的情况, 但所有的层号都加 1, 则当门打开时, STATE=NEUTRAL 或 STATE=GOINGUP 将影响电梯是有可能继续下行, 还是一定会无条件地上行.)

4\. <a id="ans-2-2-5-4"></a>[习题](../sec-2-2-5.md#ex-2-2-5-4) 如果十几人或更多人在同一层离开电梯, 则在这一段时间, STATE 可以一直为 NEUTRAL, 当 E9 调用 DECISION 子程序时, 可能新乘客还没有在当前层进入, 电梯就已经设置为新状态. 这种情况确实很少发生 (这确实也是作者进行电梯实验时观察到的最令人莫名其妙的现象).

5\. <a id="ans-2-2-5-5"></a>[习题](../sec-2-2-5.md#ex-2-2-5-5) 从时刻 1063 电梯门开始打开到时刻 1183 乘客 7 进入, STATE 将为 NEUTRAL, 因为没有到第 0 层的呼叫, 并且没有乘客在电梯上. 然后, 乘客 7 将设置 CALLCAR[2]←1, 电梯状态将相应地转变成 GOINGUP.

11\. <a id="ans-2-2-5-11"></a>[习题](../sec-2-2-5.md#ex-2-2-5-11)  初始, 对于 $1 \leq k \leq n$, 令 LINK[k]=0, 并且 HEAD=-1 在改变 V[k] 的模拟步期间, 如果 LINK[k] $\neq 0 ;$, 则给出一个错误指示; 否则, 置 LINK[k]←HEAD,HEAD←k, 并且置 NEWV[k] 为 V[k] 的新值, 在每个模拟步骤之后, 置 k←HEAD,HEAD←-1, 并且重复执行如下操作零次或多次, 直到 $k < 0$: 置 V[k] ← NEWV[k], t ← LINK[k], LINK[k] ← 0, k ← t.

<a id="pdf-459"></a><a id="p-442"></a>

显然, 如果在每个与变量字段 V 相关联的结点中包括一个 NEWV 和 LINK 字段的话, 则这种方法容易用于散布的变量.

12\. <a id="ans-2-2-5-12"></a>[习题](../sec-2-2-5.md#ex-2-2-5-12) WAIT 表从左向右删除, 但是插入从右向左排序 (因为从这一边搜索可能会短一些). 当我们不知道待删除的结点的前驱或后继时, 也从这三个表的多处删除结点. 只有 ELEVATOR 表可以转换成单向表而不会过多降低效率.

注意: 在一个离散模拟程序中, 更可取的方法是使用一个非线性表作为 WAIT, 以减少排序时间. 5.2.3 节讨论维护优先队列之类 “最小先出”(smallestin,firstout) 表的一般问题. 业已知道有多种方法, 当表中有 n 个元素时, 插入或删除只需要 O(logn) 次操作, 尽管当我们知道 n 很小时, 当然不需要这种奇思妙想的方法.
