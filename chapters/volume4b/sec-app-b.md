# 附录 B　记号索引

在下列公式中, 未作说明的字母具有如下含义.

| 字母 | 含义 |
| ---: | :--- |
| $j,k$ | 整数值算术表达式 |
| $m,n$ | 非负整数值算术表达式 |
| $p,q$ | 二进制值算术表达式 (0 或 1) |
| $x,y$ | 实数值算术表达式 |
| $z$ | 复数值算术表达式 |
| $f$ | 整数值、实数值或复数值函数 |
| $G,H$ | 图 |
| $S,T$ | 集合或多重集 |
| $\mathcal F,\mathcal G$ | 集合族 |
| $u,v$ | 图的顶点 |
| $\alpha,\beta$ | 符号串 |

定义位置或是本卷的页码, 或是其他卷的节号. 许多别的记号列在书末的总索引中, 例如以 $K_n$ 表示 $n$ 个顶点上的完全图. 另见该索引中的 “记号约定”.
